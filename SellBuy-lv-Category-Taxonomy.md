# SellBuy-lv Category Taxonomy

## Cars
- Brand: enum (options: Audi, BMW, VW)
- Year: number
- Mileage: number

## Real Estate
- Type: enum (options: apartment, house, land)
- Rooms: number
- Area: number

## Phones
- Brand: enum (options: Apple, Samsung, Xiaomi)
- Storage: number

## Fashion
- Gender: enum (options: men, women, unisex)
- Size: string

## Animals
- Species: enum (options: dog, cat, other)
- Age: number

## Jobs
- Category: enum (options: IT, construction, service)
- Salary: number
