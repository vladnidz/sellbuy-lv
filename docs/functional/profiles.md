# Functional Specification: Profiles & Ratings

User profiles are the center of trust on SellBuy.lv.

## User Profile
- Contains public information (Name, City, Join Date).
- Listings are linked to the user's ID.

## Ratings & Trust
- Users can rate transactions after a purchase.
- The rating system is essential for SS.lv competition (trust-first marketplace).
- Ratings are averaged and displayed on the user profile.
